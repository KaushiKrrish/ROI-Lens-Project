# Project Overview

**ROI Lens** is a marketing analytics project that aims to optimize digital marketing budget allocation using **Multi-Touch Attribution (Markov Chains)** instead of traditional attribution models.

The project analyzes customer journeys across multiple digital marketing channels, removes suspicious bot traffic, identifies the true contribution of each marketing channel, and recommends an optimized allocation of a ₹100 Crore marketing budget across ten brands.

Instead of relying solely on the last interaction before purchase, ROI Lens evaluates the entire customer journey to understand which channels initiate awareness, nurture users, and ultimately drive conversions.

---

# Problem Statement

Modern customers interact with multiple marketing channels before making a purchase.

Traditional attribution models such as Last Click fail to identify the real contribution of each marketing channel.

The objective of this project is to:

* Analyze customer journeys
* Remove bot traffic
* Build a Multi-Touch Attribution framework
* Identify top-of-funnel and conversion-driving channels
* Calculate true Cost Per Acquisition (CPA)
* Optimize marketing budget allocation using business constraints

## Phase 3 — Bot Traffic Detection

A rule-based anomaly detection framework was developed to identify suspicious users. Bot detection considered multiple behavioural indicators instead of relying on a single threshold.

### Detection Rules

* Excessive touchpoints
* Abnormally high impressions
* Extremely high click counts
* Unusually high CTR
* Impossible click velocity
* Very short time gaps
* Click → Purchase within an unrealistic duration
* Repeated identical customer journeys
* Campaign hammering
* Funnel violations
* Excessive Add-to-Cart events
* Abnormal purchase frequency

A composite **Bot Score** was generated by combining all anomaly flags. Users exceeding the defined Bot Score threshold were removed before attribution analysis.

## Phase 8 — Budget Optimization Framework

A constrained optimization framework was proposed.

Inputs:
* CPA
* Markov Attribution
* Primer Channels
* Closer Channels

Business Constraints:
* Maximum 40% budget per channel
* Minimum 5% allocation for active channels
* Minimum 10–15% allocation for awareness channels
* Ad Fatigue
* Diminishing Returns

Objective: To Maximize conversions while maintaining balanced marketing exposure.
